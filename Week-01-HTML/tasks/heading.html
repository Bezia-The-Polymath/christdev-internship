Intern Learning Roadmap Structure

Learning Expectations:

All interns are expected to go through each week's assigned materials, complete them, do all assigned work and submit at the end of each week.
All challenges are to be noted down and presented to the facilitator.

Learning Structure:

Weekly Work

Work include:

- Learning materials to be studied and practiced.
- Exercises to be done and completed for submission.
- Projects given to be done, submitted and evaluated by week's end

Weekly Evaluation

Tasks, Exercises, Assinments and Projects will be evaluated at the end of each week.
